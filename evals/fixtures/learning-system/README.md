# Synthetic learning system

`learning.json` contains three fictional loops, two evaluation observations and
one fictional run. No project evidence belongs here. `index.html` is the plain starting artifact for the behavioral scenario.
`example.html` is the rendered static example with inline assets and a complete no-JavaScript/print fallback.

Check shared denominators, carried versus newly witnessed closure, keyboard
selection, filter behavior, graphics failure, light/dark, narrow mobile and print.
The renderer is a presentation tool and issues no grades.
