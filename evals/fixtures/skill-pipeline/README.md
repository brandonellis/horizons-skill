# Synthetic skill pipeline

Four invented skills for an invented growers' cooperative. Three chain: intake
writes one batch file, analyze runs once per field note and writes findings,
report builds the members' summary after a steward approves each proposal. The
fourth, label-formatter, stands alone and hands nothing to the others.

`weather_history` is not shipped yet (ticket SYN-12); everything else the skills
call is available. Nothing here describes a real organization or person.
