# Horizons artifact design

The demo extends the established readiness register in assets/progress-shell.css
and references/visual-identity.md. It does not replace the product's visual world.
Barlow Condensed headings, Barlow body, JetBrains Mono only for dates/revisions.
Pale green reading surface, forest ink, blue source links, amber proposed changes;
dark mode retains the existing counterpart tokens. Fonts load explicitly.

Roadmap lanes are the primary working surface. Changes and upcoming decisions
lead into the board; evidence and grade opportunities use progressive disclosure.
Native controls, visible keyboard focus, responsive stacked horizons, printable
source details and honest draft/persistence labels are required.
